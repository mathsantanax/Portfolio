# Portfólio Pessoal - Matheus Santana

Este é meu portfólio profissional como desenvolvedor front-end, construído para centralizar meus projetos e facilitar o contato.

## 🚀 Tecnologias
- React (Vite)
- Tailwind CSS
- JavaScript/TypeScript (se aplicável)
- Deploy: Vercel

## 🎯 Decisões Técnicas
- **Vite:** Escolhido pela velocidade de build e HMR superior ao CRA.
- **Tailwind:** Para prototipagem rápida e consistência no design system.
- **Vercel:** Deploy contínuo integrado ao GitHub.

## 🖥️ Como rodar localmente
1. Clone o repo
2. `npm install`
3. `npm run dev`
